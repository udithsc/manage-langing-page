# UDT Web Solutions

Welcome to the digital landing page for **UDT Web Solutions**. This is an optimized, modern, and highly performant website built utilizing pure HTML, CSS, JavaScript, and Tailwind CSS.

## 🚀 Features
* **Modern aesthetic:** Custom UI layout aligned to the UDT Web Solutions branding.
* **Component-focused:** Hand-crafted, responsive elements using Tailwind CSS.
* **Optimized performance:** Perfect Google Lighthouse scores achieved through strict asset lazy loading, preconnections, caching, and deferred script execution.
* **Secure:** Built with strong `Content-Security-Policy` headers enforcing strict domain isolation.
* **Responsive:** Fully functions across mobile phones, tablets, and desktop devices identically.

## 🛠️ Stack
* HTML
* CSS
* JavaScript (Vanilla)
* Tailwind CSS
* FontAwesome (CDN)

## 📦 Getting Started

### Development
To start modifying the application or test it locally:

1. Install all dependencies:
```bash
npm install
```

2. Start the development server (which includes live-reloading):
```bash
npm run dev
```

### Production Build
To create a strictly optimized, compiled version of the site ready to be hosted on Netlify, run:
```bash
npm run build
```
This builds everything directly into the `/dist` directory.

To immediately preview your production `/dist` directory locally, you can serve it via:
```bash
npm run serve
```
